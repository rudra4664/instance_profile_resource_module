# New York Life Standard Terraform Modules

This repository contains the Terraform modules for specific resources for use in application deployments.

## Modules

The following modules are available for use.

| module | Source | Multi-Region Support? | Description |
| --- | --- | --- | --- |
| [terraform-aws-instance-profile-standard](modules/terraform-aws-instance-profile-standard/) | instance-profile | Yes | Standard EC2 Instance Profile |
| [terraform-aws-instance-profile-windows](modules/terraform-aws-instance-profile-windows/) | ] instance-profile | Yes | Enables features required for the Active Directory Domain Join automation |
